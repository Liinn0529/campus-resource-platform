验证日期：2026-10-28。演示服务仅监听 127.0.0.1:18081，连接本机既有 Compose 的真实 M1 与 PostgreSQL。新增内容为独立本地教学工具，没有修改正式 Web 或 M2/M3 业务。

使用 Playwright 1.62.1 驱动本机 Edge 无头浏览器，实际点击页面按钮并读取真实服务状态，结果通过：

| 操作 | 实际结果 |
| --- | --- |
| 学生预约一个座位 | HTTP 201，可约 10 → 9 |
| 存在个人预约时申请整房 | HTTP 409，可约保持 9 |
| 取消学生预约后申请整房 | HTTP 201，可约 10 → 0 |

| 清理本工具来源并开始新一轮 | 可约恢复 10，保留数据库历史 |

页面展示真实 HTTP 回执和 requestId；密码与调用令牌不发送到页面。代码凭据扫描、Python 编译和 Git 空白检查在提交前执行。既有后端完整测试结果见 member-01-validation.md，本次没有重新运行与教学工具无关的后端完整套件。
